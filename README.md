# win-iso-updater

[English](README.en.md)

**فلاشة ويندوز قديمة تدخل — ISO محدَّث يطلع. بأمر واحد.**

سكربت بايثون واحد (682 سطراً، بلا تبعيات غير `requests`): يجد ملفات التثبيت، ينزّل آخر تحديث تراكمي من كتالوج مايكروسوفت، يدمجه في الصورة، ويبني ISO يقلع على UEFI و BIOS.

بُني بعد تجهيز أكثر من 1800 جهاز يدوياً — كل جهاز كان يقضي ساعات في التحديثات بعد التثبيت.

---

## المشكلة

دمج التحديثات داخل صورة ويندوز اسمه *slipstreaming*. الفكرة معروفة، والتنفيذ اليدوي متعب.

الخطوات: تقرأ رقم البناء، تبحث في الكتالوج، تنزّل، تركّب `install.wim`، تدمج، تنظّف المكوّنات، تبني ISO. كل خطوة تنكسر بطريقتها.

هذه الأداة تنفّذها كلها بأمر واحد.

---

## كيف يشتغل

| الخطوة | الوظيفة |
|---|---|
| 1. يجد ملفات التثبيت | يبحث في كل الأقراص عن مجلد `sources` فيه `install.wim` أو `install.esd` |
| 2. يجهّز الصورة | يحوّل `ESD` إلى `WIM` قابل للتعديل، ويقرأ رقم البناء من داخلها |
| 3. يبحث | يستعلم كتالوج تحديثات مايكروسوفت عن آخر تحديث تراكمي لهذا البناء |
| 4. ينزّل | `aria2c` أولاً إن كان مثبتاً، وإلا تنزيل متوازٍ داخلي عبر HTTP Range على 8 اتصالات، ثم اتصال واحد كملاذ أخير |
| 5. يدمج | `DISM` يركّب الصورة ويدمج `.msu`/`.cab` في **كل** إصدار داخلها، ثم ينظّف المكوّنات |
| 6. يبني | `oscdimg` يخرج ISO يقلع على UEFI و BIOS معاً |

الملف المنزَّل يبقى ككاش في مجلد التحديثات؛ التشغيلة التالية تتخطّاه إذا طابق حجمه الحجم البعيد.

---

## أهم قرار في التصميم

خطأ `DISM 552` هو أشهر ما يوقف هذه العملية: نسخة DISM على الجهاز أقدم من الصورة التي تعالجها. رسالة ويندوز لا تقول ذلك.

الأداة تفحص التوافق **قبل أن تبدأ** — تقارن رقم بناء DISM برقم بناء الصورة، وتتوقف بشرح واضح وحلول (ثبّت ADK، أو مرّر `--dism`، أو تجاوز بـ `--force` على مسؤوليتك).

العملية طويلة — عشرات الدقائق. الفشل قرب نهايتها يعني إعادتها من الصفر. الفحص قبل البداية يكلّف لحظة.

## التشغيل

```bash
pip install -r requirements.txt
```

```bash
# فلاشة موصولة: اكتشاف تلقائي وتحديث الوسط في مكانه
python iso_updater.py

# من ملف ISO جاهز، مع بناء ISO جديد
python iso_updater.py --no-detect --iso "D:\Win11.iso" --out "D:\Win11-Updated.iso"
```

| الخيار | الوظيفة |
|---|---|
| `--media` | جذر وسط التثبيت يدوياً (مثل `E:\`). الافتراضي: بحث تلقائي في كل الأقراص |
| `--no-detect` | تعطيل البحث التلقائي واستخدام وضع الـ ISO |
| `--iso` | مسار ISO جاهز |
| `--out` | مكان ISO الناتج. بدونه تتحدّث الفلاشة في مكانها |
| `--updates` | مجلد حزم التحديث. الافتراضي `<الفلاشة>\updates` ككاش |
| `--connections` | عدد اتصالات التنزيل المتوازي (افتراضي 8) |
| `--no-online` | لا تبحث في الكتالوج — ادمج ملفات `.msu`/`.cab` المحلية فقط |
| `--dism` | مسار `dism.exe` أحدث (مثل الذي مع ADK) |
| `--force` | تجاوز فحص توافق DISM (متوقّع الفشل) |

الأداة فيها 17 خياراً؛ الجدول يعرض أهمها. `python iso_updater.py --help` يعرض الباقي.

**يحتاج:** Python 3.9+ · Windows ADK (`DISM` + `oscdimg`) · صلاحية مدير
